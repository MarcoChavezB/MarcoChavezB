**SIMAS Rural** — Plataforma de gestión y pagos
App móvil ciudadana que alcanzó el 10% de la recaudación total; optimización de consultas sobre millones de registros, reduciendo tiempos de respuesta de 5s a ~1s. *Stack: Laravel, Flutter*

**Multas Digitales** — Plataforma de infracciones y pagos
App móvil usada por 1,165 agentes en campo + portal de cobro ciudadano; -60% en tiempo de captura y pagos procesados en tiempo real. *Stack: PHP, Flutter, .NET 8*

**Microfin** — Plataforma de pagos de créditos
Integración de APIs para consulta de créditos, saldos y pagos, e integración de Evo Payments. *Stack: .NET 8, Flutter*

**Aviatraining and Technology** — SaaS (proyecto personal, 2023–presente)
Gestión operativa integral para escuela de aviación: automatización de inscripción, evaluación y reportes, -40% en tiempo administrativo y +30% en precisión de datos. *Stack: Angular 17, Laravel*

**DevOps / Backend** — Infraestructura para clientes web, móviles e IoT: VPC segura vía VPN, despliegues automatizados por SSH, MongoDB + MySQL con réplica esclava, proxy inverso para arquitectura modular.
